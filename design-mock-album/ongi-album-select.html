보러 가기

앨범 상세 · 선택 → 공유/이동/삭제 개선안

왼쪽 화면은 눌러 볼 수 있는 데모예요. 서버 연결 없이 흐름만 재현했어요.

이렇게 눌러보세요
  1. 사진을 길게 누르거나 오른쪽 위 「선택」을 누르면 선택 모드로 들어가요.
  2. 할머니·아빠가 올린 사진(이름 칩이 붙은 것)도 함께 골라보세요.
  3. 아래 바에서 「다른 공간에 공유」 → 공간 하나 → 앨범 하나 → 공유.
  4. 「삭제」를 누르면 내가 지울 수 있는 장수만 따로 세어 보여줘요.

지금 뭐가 불편한가 현재

  1. 내 사진만 고를 수 있어요. 다른 가족이 올린 사진은 회색으로 비활성. 공유·이동·삭제 중 삭제 권한 하나를 기준으로 선택 자체를 막고 있어요.
  2. 하단 바에 글자 버튼이 4개(모두 선택·공유·이동·삭제) 들어가 좁은 폰에서 두 줄로 꺾여요.
  3. 공유가 네이티브 액션시트 2단(공간 → 앨범)이라 어떤 사진을 보내는지 보이지 않고, 중간에 돌아가기도 안 돼요. 결과는 Alert 팝업.
  4. 선택 모드에 들어가는 길이 헤더 「선택」 하나뿐이에요.

바꾸는 것 개선

  • 모든 사진을 고를 수 있게. 권한은 선택 단계가 아니라 행동 단계에서 따져요. 공유는 누구 사진이든 가능, 이동·삭제는 내 사진(관리자는 전체)만 — 삭제 아이콘에 "가능한 장수" 배지로 미리 알려줘요.
  • 선택 모드에서만 작성자 칩 표시. 다른 사람 사진에 "할머니" 같은 칩이 붙어 왜 삭제가 안 되는지 바로 이해돼요.
  • 길게 누르기로 선택 모드 진입 + 그 사진 바로 선택. 헤더는 ✕ · "N장 선택" · 모두 선택/해제 로 정리.
  • 하단은 아이콘+짧은 라벨 3개(공유 · 앨범 이동 · 삭제). 모두 선택은 헤더로 올려 한 줄에 끝나요.
  • 공유는 바텀시트 한 장에서 끝. 보낼 사진 미리보기 → 공간 선택 → 그 공간의 앨범이 아래로 펼쳐짐 → 큼직한 「○○에 N장 공유」 버튼. 뒤로 가기도 자유로워요.
  • 삭제 확인도 시트로. 제외되는 사진이 있으면 "N장은 할머니가 올린 사진이라 제외돼요"라고 미리 말해줘요.
  • 결과는 토스트 + 「보러 가기」. Alert 로 흐름을 끊지 않아요.
